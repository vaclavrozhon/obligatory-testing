\section{Machine-checked verification}
\label{sec:formalization}

The accompanying Lean~4 development~\cite{DeMouraUllrich2021} uses
mathlib~\cite{Mathlib2020} and is pinned to version~4.30.0.  Its root module
imports every development listed below.  The following table states the proof boundary;
\cref{app:lean-formalization} gives the detailed paper--Lean dictionary for
the deterministic theorem.

The coverage column states directly whether Lean constructs the schedule
action by action, proves that each decision uses only the public transcript,
and derives the advertised cost bound.  We use \emph{one-job correction} for
the linear terms in a double sum that pair a job with itself.  The word
\texttt{fuel} in some Lean names denotes a finite upper bound on the number
of internal steps used to run a formal strategy.

The development contains no \texttt{sorry}, \texttt{admit}, or
project-defined axiom.  Formal randomized statements use finite uniform
averages for private seeds and explicit nonnegative finite weights for Yao
input laws; these cover permutations, sample choices, tie-breaking coins,
and the exact Bernoulli masses used here.  Classical real analysis and
noncomputable exact minimizers occur only inside proofs; no floating-point
program is extracted.
